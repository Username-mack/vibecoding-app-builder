# VibeCoding 应用构建器

这个 Skill 帮你用 AI 把一句应用想法整理成产品需求文档（PRD），再做成可直接使用的应用。它适合个人工具、小型管理后台和项目管理系统，也提供可复用的[提示词手册](references/prompting-playbook.md)。

## 五步工作流

1. **粗描述 → AI 补全 PRD。** 用一句话说明想做什么，由 AI 草拟应用目标、功能、数据模型和验收标准。
2. **人工做减法。** 通读初稿，删除用不到的模块，确定本次实现范围。
3. **补充视觉与交互规则。** 写明配色、布局、空状态和交互反馈，把这些规则加进 PRD。
4. **生成应用。** 同时给出四条硬约束：禁止使用假数据、真实实现增删改查、确保所有交互可用、明确并实现数据存储方式。
5. **测试与迭代。** 逐项验证交互、数据保存和刷新后的状态，修复问题后复测。

## 安装

```bash
npx skills add Username-mack/vibecoding-app-builder
```
